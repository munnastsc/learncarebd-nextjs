📘 1. Short Trick & Core Rules

১. 'Used to' এর মূল ৩টি ব্যবহার ও কনসেপ্ট

১. Past Discontinued Habit (অতীতের নিয়মিত অভ্যাস যা এখন আর নেই)

অতীতে কোনো কাজ নিয়মিত করা হতো কিন্তু বর্তমানে তা সম্পূর্ণ বন্ধ হয়ে গেছে।
উদাহরণ: I used to play badminton every winter. (এখন আর খেলি না)

২. Past State (অতীতের অবস্থা বা অস্তিত্ব)

অতীতে কোনো ব্যক্তি বা বস্তুর কোনো নির্দিষ্ট অবস্থা ছিল যা এখন আর নেই।
উদাহরণ: There used to be a large banyan tree here. (এখন গাছটি নেই)

৩. 'Used to + V1' বনাম 'Be used to + V(ing)' (মারাত্মক পার্থক্য!)

• Used to + V1: অতীতের অভ্যাস (I used to wake up early = আগে উঠতাম, এখন উঠি না)
• am/is/are used to + V(ing): বর্তমানের অভ্যস্ততা (I am used to waking up early = আমি ভোরে উঠতে অভ্যস্ত)

৪. 'Used to' বনাম 'Would'

অতীতের Action বোঝাতে used to এবং would দুটোই বসে (He used to/would swim). কিন্তু অতীতের State (অবস্থা/থাকা) বোঝাতে কেবল used to বসে, কখনোই 'would' বসে না!
সঠিক: He used to be a teacher. (He would be a teacher ভুল!)

২. The 6 Golden Spoken Sentence Structures

Pattern No.Structure NameFormulaPractical Spoken Example
1Affirmative (+)Sub + used to + V1 + ObjectI used to live in Chittagong during childhood.
2Negative (-)Sub + didn't use to + V1 + ObjectHe didn't use to like vegetables when he was young.
3Interrogative (?)Did + Sub + use to + V1 + Object...?Did you use to play football in school?
4Negative Interrogative (-?)Didn't + Sub + use to + V1...?Didn't there use to be a cinema hall here?
5Present Familiarity (Be used to)Sub + am/is/are used to + V(ing)I am used to working in noisy environments.
6WH-Question (+)WH + did + Sub + use to + V1...?Where did you use to hang out with friends?
